# Grup1_AuthProject - Authentication Modülü

Bu proje, **Bilgisayar Mühendisliğinde Proje Yönetimi** dersi **Jira & GitHub Entegrasyonu ile Kanban Uygulaması** laboratuvar çalışması kapsamında geliştirilmiştir.

## Roller
- **Product Owner (PO):** Backlog yönetimi ve önceliklendirme
- **Frontend Developer:** React arayüz bileşenleri (`AUTH-1`, `AUTH-2`, `AUTH-3`)
- **Backend Developer:** REST API ve veri katmanı (`AUTH-4`, `AUTH-5`, `AUTH-6`)
- **Tüm Ekip:** Modül Entegrasyon Testleri (`AUTH-7`)

## Kurulum ve Çalıştırma
```bash
npm start
```
Sunucu `http://localhost:3001` adresinde çalışır ve React arayüzünü sunar.

## Entegrasyon Testleri
```bash
npm test
```
